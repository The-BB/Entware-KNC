    uboot-sifiveu: disable mkeficapsule host tool
    
    Since the bump to 2026.04, tools/Kconfig defaults TOOLS_MKEFICAPSULE to
    y whenever EFI_LOADER is set, which both SiFive configs enable. The host
    tool includes <gnutls/gnutls.h>, which the build system does not provide,
    so the package fails to compile. Disable the tool, as the other U-Boot
    packages carrying an EFI_LOADER config already do.
