    realtek: dsa: convert direct LAG register accesses to regmap
    
    The LAG code still uses raw switch register accessors despite the
    regmap already available in the switch private data.
    
    Replace direct register accesses with regmap operations through
    priv->map. Pass priv to the local group, local port and table refresh
    callbacks, updating their declarations and callers accordingly.
    
    Use regmap_write_bits() to preserve unconditional masked writes and
    include all set bits in the mask to retain sw_w32_mask() semantics.
    Convert refresh polling to regmap_read_poll_timeout() while keeping
    the existing polling interval and timeout.
